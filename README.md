# Indian Railway Database Explorer

A powerful, interactive dashboard for exploring the Indian Railway network, built with Python and Streamlit. This application provides insightful metrics on train categories, station data, and route logistics.

## Features

*   **Overview Dashboard**: Visual breakdown of total trains, stations, and route stops with category-based charting (Express, Passenger, SuperFast).
*   **Train Search**: Easily search and filter through railway data.
*   **Station Explorer**: Investigate station-specific information and network connectivity.
*   **Data Quality**: Monitor and validate the integrity of the railway dataset.

## Technology Stack

*   **Frontend/Dashboard**: [Streamlit](https://streamlit.io/)
*   **Data Processing**: Python, Pandas, NumPy
*   **Database**: SQLite / Local Database
*   **Visualization**: Streamlit native charts

## Getting Started

### Prerequisites

*   Python 3.x
*   `pip` (Python package installer)

### Installation

1.  **Clone the repository**:
    ```bash
    git clone [https://github.com/YOUR_USERNAME/indian-railway-explorer.git](https://github.com/YOUR_USERNAME/indian-railway-explorer.git)
    cd indian-railway-explorer
    ```

2.  **Set up a virtual environment (optional but recommended)**:
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Run the application**:
    ```bash
    streamlit run app.py
    ```
